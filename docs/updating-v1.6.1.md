# Mail Samurai v1.6.1 更新ガイド

## 変更内容

v1.6.1では単発メルマガの配信準備を修正した。宛先をすべて登録してから送信待ちにする。宛先登録の途中でCronが動いても、作成途中の配信を送信・完了扱いにしない。

| 管理画面の状態 | 意味 |
|---|---|
| 宛先準備中（長時間続く場合は要確認） | 配信対象の登録処理中。この配信はまだ送信しない |
| 送信待ち | 宛先の登録が完了。定期処理で順次送信する |
| 準備失敗（未送信） | 配信準備に失敗。この配信は送信しない |
| 完了 | 配信キューの処理が完了。各宛先への送信状況も確認する。宛先が0件の場合も完了になる |

「準備失敗」は配信を作る段階の失敗。「送信状況」の失敗通数は宛先ごとの送信処理の失敗で、別の意味になる。

## 更新手順

1. [v1.6.1リリース](https://github.com/ecsamurai/mail-samurai/releases/tag/v1.6.1)のAssetsから`mail-samurai-1.6.1.zip`をダウンロードする。
2. WordPressの「プラグイン → プラグインを追加 → プラグインのアップロード」でZIPを選ぶ。
3. 「現在のものをアップロードしたもので置き換える」を選ぶ。更新のためにプラグインを削除しない。
4. インストール済みプラグインでバージョン1.6.1を確認する。

購読者、シーケンス、配信記録、行動履歴は維持する。更新前に完了扱いになっている配信を自動で再送する機能はない。
